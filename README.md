# Surrogate Calibration and Optimisation

Research code for Gaussian process surrogate modelling, uncertainty calibration, and multi-objective optimisation with small datasets.

The workflows cover model selection, bagging, conformal calibration, and Pareto-front approximation across three experiment groups:

- **Analytical benchmarks:** FON and DTLZ2.
- **Public battery datasets:** Li and Verma, including nested repeated validation.
- **In-house simulation:** a battery thermal management case study with simulation-based validation.

The repository includes experiment code, input datasets, reference results, and scripts for regenerating figures and tables. Experiment settings and running instructions are provided in [docs/](docs/).
